# Демо оқу парақтары

Осы алты шағын PDF EduShelf демонстрациясына арнайы жазылды. Әр парақта оқу мақсаты, қысқа түсіндіру, тапсырмалар және жауап үлгісі бар. Бұлар сыртқы басылымнан алынған оқулықтар немесе жасанды AI талдау нәтижелері емес.

PDF файлдарында қазақша таңбаларды қолдайтын қаріп енгізілген. Қайта жасау үшін Python және `reportlab` орнатыңыз, содан кейін жоба түбірінен `python scripts/generate-demo-pdfs.py` орындаңыз. Windows сыртында қазақша әріптерді қамтитын TrueType қаріпке `--font` және `--bold-font` параметрлерін беріңіз.

Файлдар бастапқы демо активтері ретінде сақталады. Seeder оларды `wwwroot` сыртындағы файл қоймасына қалыпты жүктеу тексеруінен өткізіп көшіреді; каталог жүктеулерді тек рұқсат тексеретін endpoint арқылы береді.
