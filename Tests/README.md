# Тексерулер

`dotnet test Tests/EduShelf.Tests.csproj` файл қоймасы мен рұқсат ережелерінің unit тексерулерін орындайды. SQL Server қосылымы берілмесе, SQL integration тексерулері өткізіліп, нақты себебі тест нәтижесінде көрсетіледі.

SQL Server тексерулері үшін PowerShell сессиясында қосылымды беріңіз. Сервер мәнін өзіңіз тексерген instance атауымен ауыстырыңыз:

```powershell
$env:EDUSHELF_TEST_CONNECTION = 'Server=.;Database=master;Trusted_Connection=True;Encrypt=True;TrustServerCertificate=True;Connect Timeout=5'
dotnet test Tests/EduShelf.Tests.csproj
```

Тест қолданушысына `CREATE DATABASE` құқығы қажет. Fixture көрсетілген серверде тек өзі жасаған `EduShelf_Tests_<guid>` атаулы уақытша базаларды қолданады, негізгі қолданба базасына тимейді және аяқталғанда уақытша базаларды жояды. Қосылымдағы бастапқы database атауы тест қолданбасының базасы ретінде пайдаланылмайды. CI үзілген жағдайда осы префикспен қалған тест базаларын әкімші тексеріп жоя алады.

Integration тексерулері шынайы SQL Server provider мен жобаның EF миграциясын қолданады. Олар favorites бірегейлігін және қатар орындалуын, жасырын метадеректерді сүзуді, пән-тақырып сәйкестігін service пен SQL FK деңгейінде, сақтау қатесіндегі файлды тазалауды, ескірген нұсқаның жаңарту қақтығысын, соңғы әкімшіні қорғауды және demo seed қайталануын тексереді. Бөлек тест жасалған SQL скриптін екі рет орындап, кестелерді, бағандарды, индекстерді және constraint құрылымын миграция арқылы құрылған базамен салыстырады.

Windows-та қолданба іске қосылып тұрса, оның `.exe` және `.dll` файлдары Debug build-ке кедергі келтіруі мүмкін. Қолданбаны тоқтатыңыз немесе тест үшін бөлек `dotnet test Tests/EduShelf.Tests.csproj -c Release` қолданыңыз.
